# Diagrama: Estrutura do pom.xml

Gere um mapa mental em Markdown a partir do arquivo `pom.xml` que represente:

- Nome e versão do projeto
- Tipo de projeto (ex: Spring Boot, multimódulo)
- Lista de dependências principais
  - Frameworks utilizados (ex: Spring Boot Starter Web, Data, Security)
  - Bibliotecas auxiliares (ex: Lombok, MapStruct, OpenAPI, etc)
- Plugins configurados (ex: spring-boot-maven-plugin, maven-compiler-plugin)
- Perfis de build (dev, prod, test, etc)

Formato: Markdown estruturado, adequado para renderização com Markmap.
