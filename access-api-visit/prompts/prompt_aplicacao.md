# Mapeamento de Arquitetura - Microsserviços (API REST)

> Este documento serve como base para o GitHub Copilot mapear a arquitetura da aplicação de microsserviços implementada.

## Objetivo

1. **Nome do microsserviço**  
2. **Descrição funcional**  
3. **Domínio e subdomínio de negócio**  
4. **Endpoints REST expostos**  
5. **Chamadas REST para outros microsserviços**  
6. **Banco de dados utilizado**, se aplicável
7. **Mensageria utilizada**, se aplicável (ex: Kafka, RabbitMQ, JMS, etc)  
8. **Padrão arquitetural** (ex: Hexagonal, CQRS, Camadas, etc)  
9. **Segurança** (ex: JWT, OAuth2, Keycloak, istio, access-management, etc)  
10. **Dependências externas**
