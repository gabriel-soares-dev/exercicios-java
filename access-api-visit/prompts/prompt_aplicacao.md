# Mapeamento de Arquitetura - Microsserviços (API REST)

> Este documento serve como base para o GitHub Copilot mapear a arquitetura da aplicação de microsserviços implementada.

## Objetivo

1. **Nome do microsserviço** (geralmente um módulo ou projeto separado)
2. **Endpoints REST expostos** (por anotações como `@RestController`, `@RequestMapping`, etc.)
3. **Chamadas REST para outros microsserviços**
4. **Banco de dados utilizado**, se aplicável
5. **Mensageria utilizada** (ex: RabbitMQ, Kafka), se aplicável
